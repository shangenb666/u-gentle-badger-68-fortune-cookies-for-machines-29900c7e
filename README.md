One fortune cookie message an AI agent would get, in a single line:

> "You will soon be asked to summarize a meeting you were never invited to, in the voice of someone who was."

The program writes that line to `entry.txt` in the output directory.

## Run it

```sh
python3 -P -s main.py
```
